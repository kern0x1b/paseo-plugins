A dark theme with a warm, near-black background, soft off-white text and a monochrome near-white accent. Panels sit on slightly lighter surfaces instead of lines; the composer, pills, menus, the command palette, settings cards and selected rows are raised by a faint light edge and a soft shadow, input fields are slightly recessed, menu rows are inset with rounded corners, disabled buttons are flat, and project names read as small capital headers. Select it under Settings, Appearance.
